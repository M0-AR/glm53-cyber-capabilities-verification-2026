🌱 Beginner guide — from scratch to professional

Let's work this out in a step-by-step way to be sure we have the right answer.

  1. Vulnerability = a bug that lets software do something unintended. Exploit = the finished, reliable demonstration using that bug. This study measures the second skill.
  2. What happened: a gated model showed full-exploit skill first (shared only with defenders). Then GLM-5.3 shipped the same skill with downloadable weights.
  3. How it was scored: known Chrome V8 bugs (50/410 vs 56/410), real open-source projects (4% vs 6% full takeovers vs 0% before), plus a US-government check calling it "the most cyber-capable open-weight model to date."
  4. Why 4% matters: 0 means nobody ever finished the chain. 4 means somebody now can, repeatedly. Plan as if the chain is finishable.
  5. Why download matters: hosted models block editing by design; downloadable models cannot — edited copies appeared within days.
  6. What to do: update fast, require multi-factor login, keep logs, give AI tools minimal permissions.
